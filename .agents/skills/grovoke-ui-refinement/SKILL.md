# Grovoke UI refinement
Adapted from Leonxlnx/taste-skill's redesign-skill at commit
18dfc928b135629e0eddfdd445a06400d04ed439; see LICENSE.

Read root AGENTS.md and DESIGN.md, then inspect the requested component and
existing shared primitives. Identify specific hierarchy, spacing, focus, loading,
empty, error, and responsive issues. Apply targeted changes within the existing
stack and verify observable behavior.

Use tabular figures for numbers, consistent icon strokes, concise copy, semantic
HTML and visible keyboard focus. Preserve Inter, JetBrains Mono, lucide-react,
light surfaces, blue primary actions and meaningful semantic status colors.
Keep dense operational tables and call controls. Do not apply upstream font swaps,
new icon libraries, marketing whitespace, parallax, random imagery or ornamental
effects. Use synthetic data only; verify through docs/codex-workflow.md.
